# Interface localisation (BL-12) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show the whole interface — panel, module cards, 3D labels, generated
sentences — in any of eight languages, chosen from a switcher and remembered
between visits.

**Architecture:** A pure `src/i18n.js` holds lookup, formatting and locale
matching, and knows nothing of Three.js or the DOM, so it can be tested under
Node like `engineState.js` and `contrail.js`. Eight locale files are plain ES
modules, all bundled. Static markup carries `data-i18n` keys; everything built
at runtime resolves through `t()` at display time, which is what makes live
language switching work.

**Tech Stack:** Plain ES modules, Vite, Three.js, `Intl.NumberFormat`, Node's
built-in test style (no framework).

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-06-i18n-design.md`. It is authoritative;
  where this plan and the spec disagree, the spec wins.
- **Do not commit.** The user asked for the change to be left uncommitted.
  Wherever the ordinary workflow would commit, run `npm test` instead and leave
  the tree dirty.
- Locales, in `available` order: `en`, `ru`, `es`, `zh-Hans`, `fr`, `pt-BR`,
  `de`, `ja`. `en` is source and fallback.
- Written language of code, comments and docs is English. Comments explain
  **why**, not mechanics.
- SI unit symbols are never translated: `°C`, `bar`, `kN`, `km`, `rpm`, `%`,
  `Pa`, `kg/m³`, `Pa/K`.
- No external assets, no new dependencies.
- `src/i18n.js` must not import Three.js or touch `document`.
- Storage key: `turbofan.lang`. All `localStorage` access wrapped in
  `try`/`catch`.
- Tests are plain Node scripts with a local `check()` helper, one `OK`/`FAIL`
  line per check, `process.exit(1)` on failure.

- [ ] **Step 3: Write `src/i18n.js`**

```js
/* Localisation, kept free of Three.js and the DOM for the same reason as
 * engineState and contrail: a headless browser renders this scene at about
 * 1 fps, so anything worth testing has to run under Node. */

/** Longest-prefix match of the reader's languages against what we have. */
export function pickLocale(preferred, available) {
  for (const want of preferred || []) {
    const tag = String(want);
    // exact, then language-only: pt-PT and pt-BR both answer to "pt", which
    // is how a Portuguese reader lands on the Brazilian text rather than on
    // English.
    const hit =
      available.find((a) => a.toLowerCase() === tag.toLowerCase()) ||
      available.find((a) => a.toLowerCase().split('-')[0] === tag.toLowerCase().split('-')[0]);
    if (hit) return hit;
  }
  return 'en';
}

export function createI18n({ locales, initial }) {
  const tags = Object.keys(locales);
  let current = locales[initial] ? initial : 'en';

  // Intl.NumberFormat is expensive to construct and updateGauges formats
  // nineteen numbers per call from the frame loop, so the formatters are made
  // once per digit count and thrown away only when the language changes.
  let formatters = new Map();

  const t = (key, params) => {
    const raw = locales[current]?.[key] ?? locales.en?.[key] ?? key;
    if (!params) return raw;
    return raw.replace(/\{(\w+)\}/g, (m, name) =>
      Object.prototype.hasOwnProperty.call(params, name) ? params[name] : m
    );
  };

  const n = (value, digits) => {
    let f = formatters.get(digits);
    if (!f) {
      f = new Intl.NumberFormat(current, {
        minimumFractionDigits: digits,
        maximumFractionDigits: digits,
      });
      formatters.set(digits, f);
    }
    return f.format(value);
  };

  return {
    t,
    n,
    locale: () => current,
    available: () => tags.slice(),
    setLocale(tag) {
      if (!locales[tag]) return;
      current = tag;
      formatters = new Map();
    },
  };
}
```

```js
import { readFileSync } from 'node:fs';

const html = readFileSync(new URL('../index.html', import.meta.url), 'utf8');
const EN = LOCALES.en;

// Every data-i18n names a key we have, and the English left in the markup is
// the same English the dictionary holds. The markup keeps its text so the file
// stays readable and the panel is not blank for the tick before the module
// graph evaluates - which leaves two copies of en, and this is what stops them
// drifting apart.
const norm = (s) => s.replace(/\s+/g, ' ').trim();
const tagged = [...html.matchAll(/<(\w+)[^>]*\sdata-i18n="([^"]+)"[^>]*>([\s\S]*?)<\/\1>/g)];
check('markup: data-i18n found', tagged.length > 20, `${tagged.length} tagged`);

// Reported in the aggregate rather than one check per element: there are some
// eighty of them, and a per-element line would bury the rest of the suite and
// inflate the check count the documentation quotes.
const unknown = tagged.filter(([, , k]) => !(k in EN)).map(([, , k]) => k);
check('markup: every key exists in en', unknown.length === 0, unknown.join(', '));

const mismatched = tagged
  .filter(([, , k, body]) => k in EN && norm(body) !== norm(EN[k]))
  .map(([, , k, body]) => `${k}: markup ${JSON.stringify(norm(body))} vs en ${JSON.stringify(norm(EN[k]))}`);
check('markup: English matches the dictionary', mismatched.length === 0, mismatched.join('; '));

// applyStatic assigns textContent, so a data-i18n on a parent with children
// would silently delete them. Forbidding the shape is cheaper than detecting
// the damage.
const nested = tagged.filter(([, , , body]) => /</.test(body)).map(([, , k]) => k);
check('markup: no tagged element has child tags', nested.length === 0, nested.join(', '));
```

Near the top of the file, before `buildEngine()` is called:

```js
import { createI18n, pickLocale } from './i18n.js';
import LOCALES from './locales/index.js';

const STORE_KEY = 'turbofan.lang';

// localStorage throws in private mode and in a sandboxed iframe, and the model
// has to keep running without remembering the choice.
function storedLang() {
  try { return localStorage.getItem(STORE_KEY); } catch { return null; }
}
function storeLang(tag) {
  try { localStorage.setItem(STORE_KEY, tag); } catch { /* not fatal */ }
}

const i18n = createI18n({
  locales: LOCALES,
  initial: storedLang() || pickLocale(navigator.languages, Object.keys(LOCALES)),
});
const { t, n } = i18n;

function applyStatic() {
  // querySelectorAll reaches into <head>, and textContent on <title> is
  // document.title, so the tab caption needs no special case.
  document.querySelectorAll('[data-i18n]').forEach((el) => {
    el.textContent = t(el.dataset.i18n);
  });
  document.documentElement.lang = i18n.locale();
}

// runs before buildEngine so the loading line is already in the reader's
// language for all but the tick the module graph takes to evaluate
applyStatic();
```

`src/main.js:437`, while `let gaugeShown = -1` is declared at `:441`. Wrapping
the assignment in a function that touches `gaugeShown` and calling it in place
would read the binding inside its temporal dead zone and throw a
`ReferenceError` at start-up. So move the declaration above the function:

```js

```

with the call where the old `innerHTML` assignment used to be, and delete the
now-duplicated `let gaugeShown = -1` that stood at `:441`.
